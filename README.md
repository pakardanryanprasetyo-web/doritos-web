# Website SMK Muhammadiyah Pakem

Website profil sekolah (HTML, CSS, JavaScript) dengan menu Beranda, Profil Sekolah, Program Keahlian, Berita, Galeri, dan Kontak. Tampilan responsif untuk laptop dan ponsel.

## Isi

| File | Fungsi |
| --- | --- |
| `index.html` | Isi halaman |
| `style.css` | Tampilan |
| `script.js` | Menu ponsel, tema gelap/terang, galeri foto |
| `images/` | Logo dan foto sekolah |

## Cara menayangkan dengan GitHub Pages

1. Unggah semua file ini ke repository Public.
2. Buka **Settings > Pages**.
3. Pada **Branch**, pilih `main` dan folder `/ (root)`, lalu klik **Save**.
4. Tunggu 1 sampai 2 menit. Alamat website muncul di bagian atas halaman Pages, contohnya `https://username.github.io/nama-repo/`.

## Mengubah isi

- Teks: edit `index.html`.
- Foto galeri: simpan foto di folder `images`, lalu tambahkan barisnya pada daftar `items` di `script.js`.
